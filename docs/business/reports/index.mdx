# Reports

Ottu lets you export and download your payment data at any time. Whether you need a snapshot of today's transactions or a record of wallet activity, the reports system gives you a file you can open in Excel, share with your finance team, or archive for compliance.

This guide covers everything from generating your first export to re-downloading a file you created last week.

## How it works

When you export data from any screen in Ottu — the Transactions page, wallet activity, or other sections — Ottu queues a file to be generated in the background. This usually takes a few seconds to a few minutes depending on how many records are included.

Once the file is ready, it appears in the **Generated Reports** page, where you can download it for 30 days (event booking exports are the one exception — see [Event Bookings](#event-bookings)). You do not need to wait on the screen where you clicked Export — you can close the browser, come back later, and the file will still be there.

:::note
Which reports you see in Generated Reports depends on your dashboard permissions. The **Exported By** column shows who created each export. Rows with no name in that column are scheduled reports that Ottu generates automatically — see [Transaction Report Configuration](/business/settings/transaction-reports).
:::

### What gets exported

Every export produces a spreadsheet file you can open in Excel, Google Sheets, or any spreadsheet tool. You choose the format when you export — **CSV** or **XLSX**.

| What you export | Where you start | What the file contains |
|---|---|---|
| Payment transactions | Transactions page | Payment links, amounts, statuses, gateway info |
| Wallet activity | Wallet → Accounts → an account | Wallet credits, debits, and balances |
| Event bookings | Events → Bookings | One row per booking, with customer and event details |

:::tip
If you need reports delivered automatically on a schedule — for example, a daily CSV emailed to your finance team — see [Transaction Report Configuration](/business/settings/transaction-reports) under Settings.
:::

:::warning
The columns in your exported file are the ones you tick in the **export panel** — not the columns visible in your transactions table. Changing your table headers does not change the export, and vice versa. Check the panel before every export to make sure the fields you need are ticked.

:::tip
Set the **Timezone** in the export panel to match the timezone your finance team works in. Otherwise date and time columns may appear shifted by several hours once the file is opened, and reconciling against your own records gets confusing.
:::

## Export Sources

Ottu offers export from multiple screens in the dashboard. Every export source produces a **CSV** or **XLSX** file, and transaction and wallet exports all land in the same **Generated Reports** download center. The one exception is [Event Bookings](#event-bookings), which has its own download list.

### Transactions

The main export source. Each [plugin](/business/plugins) has its own **Transactions** page with an **Export Transactions** button, and every export covers only that plugin's transactions. The steps are the same everywhere, so the [Generate a Report](#generate-a-report) walkthrough above applies to all of them.

**Where:** Dashboard → Payment Request → Transactions → **Export Transactions** (or the Transactions page of any other plugin, listed in [Other Export Sources](#other-export-sources) below)

**What you get:** One row per transaction, including amount, currency, payment status, gateway, creation date, customer details, and any custom columns you have configured.

### Wallet Reports

If your account uses the [M-Wallet](/business/wallet/) feature, you can export wallet ledger entries — credits, debits, and operations — directly from any customer wallet account.

**Where:** Dashboard → Wallet → Accounts → (open an account) → **Export Entries**

**What you get:** One row per wallet ledger entry, including event type (credit/debit/reservation), amount, currency, customer ID, status, and linked payment session.

### Event Bookings

If your account uses the Events plugin, you can export the list of bookings for your events. Event booking exports work differently from every other source: the file does **not** appear in Generated Reports. It has its own list under **Events → Event Reports**.

**Where:** Dashboard → Events → Bookings → **Export Bookings**

**What you get:** One row per booking, including the event, quantity, customer name, purchase type (free or paid), email, event date, booking date, and customer phone.

1. Go to **Events → Bookings** and click **Export Bookings**.
2. In the menu that opens, under **Select file type**, choose **CSV** or **XLSX**.
3. Click **Export Bookings** in the menu. A green *"Your export request was successful"* message confirms the request.
4. Go to **Events → Event Reports**. Your export is listed with its file format and number of records. Click the green **download icon** in the **Download URL** column to download the file.

:::warning
Don't look for event booking exports in **Generated Reports** — they only appear under **Events → Event Reports**.
:::

### Other Export Sources

The following screens also have an **Export Transactions** button. Each works exactly like the [Transactions export](#generate-a-report): open the export panel, choose columns, timezone and file type, click **EXPORT**, and collect the file from Generated Reports.

| Section | How to reach it |
|---|---|
| **Payment Request — deleted transactions** | Dashboard → Payment Request → Deleted Paid Transactions → **Export Transactions** |
| **Bulk** | Dashboard → Bulk → Transactions (or Deleted Paid Transactions) → **Export Transactions** |
| **Customer Payment** | Dashboard → Customer payment → Transactions (or Deleted Paid Transactions) → **Export Transactions** |
| **Catalogue** | Dashboard → Catalogue → Transactions (or Deleted Paid Transactions) → **Export Transactions** |
| **E-Commerce** | Dashboard → E-commerce → Transactions (or Deleted Paid Transactions) → **Export Transactions** |
| **Refund Transactions** | Dashboard → Refund Transactions → **Export Transactions** |

:::note
**Invoices**, **Bulk Uploads**, **Access Logs**, and the **Tickets** approval queue do not have an export option.
:::

:::note
The exact sections available in your dashboard depend on which [plugins](/business/plugins) are enabled for your merchant account. If a section listed above is not visible, it may not be activated. Contact your Ottu account manager to enable it.
:::
