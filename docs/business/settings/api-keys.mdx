# How to Get API Keys

API keys allow your developers to authenticate with the Ottu API and integrate payment functionality into your application. Each key pair consists of a **private key** (for server-side API calls) and a **public key** (for client-side SDK initialization). A private key can be **full access** or **scoped** to an explicit set of permissions — see the [API Key Permissions](/developers/reference/api-key-permissions) catalog.

For technical details on how API keys are used in authentication, see the [developer authentication guide](/developers/getting-started/authentication).
