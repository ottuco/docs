# Export Transactions and Generate a Report

To get a report of your payments, export the transactions table of a [plugin](/business/plugins) to a CSV or Excel file. The export contains exactly the transactions the table is showing, so [filter](/business/payment-management/search-and-filter) first if you only want some of them, for example only the unpaid ones.

**Who can do it:** any dashboard user. You export the transactions you are allowed to see. If transactions are missing, see [Why can't I see all the transactions?](/business/users-and-access/transaction-visibility)

:::tip
Need the same report every day, week or month, sent by email or SFTP? Set up a [scheduled transaction report](/business/settings/transaction-reports) instead.
:::

## How do I export my transactions?

<StepShow>
  <Step image="/img/business/payment-management/export-sidebar.png" spot="19,53,42,13" alt="The dashboard sidebar with Payment Request open and Transactions selected">
    In the sidebar, open the plugin, for example **Payment Request**, and click **Transactions**.
  </Step>
  <Step image="/img/business/payment-management/filter-panel.png" spot="2,3,96,10" alt="The Filter panel with State, the other filters, Search and Reset">
    Optional: click **Filter**, choose what you want to see, for example a **Created** period or a **State**, and click **Search**. The export keeps your filters and your search.
  </Step>
  <Step image="/img/business/payment-management/export-toolbar.png" spot="39,26,33,31" alt="The Export Transactions button above the transactions table, next to Filter">
    Click **Export Transactions** above the table.
  </Step>
  <Step image="/img/business/payment-management/export-options.png" spot="5,44,91,15" alt="The export options with Timezone and Select timezone">
    Under **Timezone**, pick a timezone in **Select timezone** if the dates in the file should use a specific one.
  </Step>
  <Step image="/img/business/payment-management/export-options.png" spot="5,69,32,16" alt="The export options with Select file type: CSV or XLSX">
    Under **Select file type**, choose **CSV** or **XLSX**.
  </Step>
  <Step image="/img/business/payment-management/export-options.png" spot="77,90,21,9.5" alt="The Export button at the bottom of the export options">
    Click **Export**.
  </Step>
  <Step image="/img/business/payment-management/generated-reports.png" spot="81,23,9.5,16.5" alt="The Generated Reports table with the Available until and Download columns">
    The **Generated Reports** page opens. The file is prepared in the background: when your export shows a download icon in the **Download** column, click it.
  </Step>
</StepShow>

You can leave the page while the file is prepared. To come back later, click **Generated Reports** in the sidebar. Each file stays there until the date in its **Available until** column. You see only your own exports.

The file has one row per payment. Refunds, voids and captures made on a payment are not separate rows.

## How do I export only the unpaid transactions?

<StepShow>

<Step image="/img/business/payment-management/export-sidebar.png" spot="19,53,42,13" alt="The dashboard sidebar with Payment Request open and Transactions selected">

Open the plugin's **Transactions** table.

</Step>

<Step image="/img/business/payment-management/export-toolbar.png" spot="72.8,25.8,21.2,31" alt="The Filter button above the transactions table">

Click **Filter**.

</Step>

<Step image="/img/business/dashboard/state-unpaid.png" spot="3.2,79.6,90,15.3" alt="The State filter open, with All Unpaid at the end of the list">

In **State**, choose **All Unpaid**.

</Step>

<Step image="/img/business/payment-management/filter-panel.png" spot="22.4,85.6,27,10.6" alt="The Search button at the bottom of the Filter panel">

Click **Search**. The table now shows only unpaid transactions.

</Step>

<Step image="/img/business/payment-management/export-toolbar.png" spot="39,26,33,31" alt="The Export Transactions button above the transactions table">

Click **Export Transactions**, choose **CSV** or **XLSX**, and click **Export**.

</Step>

<Step image="/img/business/payment-management/generated-reports.png" spot="81,23,9.5,16.5" alt="The Generated Reports table with the Download column">

Download the file from the **Generated Reports** page.

</Step>

</StepShow>

**All Unpaid** covers the states Created, Pending, Attempted, Failed, Expired and Unavailable. To export the paid ones, choose **Paid** in step 3. See [Transaction States](/business/payment-management/transaction-states) for what each state means.

If there is no **State** filter, your administrator has removed it. Ask them to add it back in [the filters configuration](/business/payment-management/search-and-filter#choose-the-filters-and-search-fields).

## My export takes too long or never finishes

A large export can take a long time, and an export that runs for more than an hour is stopped. Export a smaller set of transactions each time:

1. Open the **Transactions** table and click **Filter**.
2. In the **Created** filter, set a period of **one month**, then click **Search**.
3. Click **Export Transactions** and export that month.
4. Repeat for the next month.

Other things that help:

- Choose **CSV** instead of **XLSX**. An Excel sheet cannot hold more than 1,048,576 rows, and rows above that limit are left out of an XLSX file.
- Add more filters, such as **State** or the connector, so that fewer transactions are exported.
- If the **Download** column shows a red **X**, the export failed. Hover over it to read the reason, then try again with a shorter period.

## Choose the columns of the file

The columns come from the plugin's dashboard report configuration. An administrator sets them in **Administration panel** > **Report** > **Dashboard report configs**: see [Dashboard Export](/business/settings/transaction-reports#dashboard-export).

Users with the **Can view export settings** permission also see the list of columns in the export window and can untick the ones they do not want.
