# The Old Webhook Docs

The old webhooks (format 2) are obsolete. Ottu still sends them to the accounts that use them, and never switches an account on its own. Every new integration uses [webhooks v3](/developers/webhooks).

## The old pages {#pages}

#### Payment notification {#payment-notification}

[The body Ottu sends when a payment is processed](/developers/webhooks/payment-events): its fields, how to set it on a payment, and how `200` and `201` change the payer's redirect.

#### Operation notification {#operation-notification}

[The body Ottu sends after a refund, capture or void](/developers/webhooks/operation-events), including the pending `refund_queued` state.

## Move to v3 {#move-to-v3}

v3 sends every webhook as an event, with the payment itself in `data`, and renames two values: `refund_queued` is `refund_pending`, and `invalided` is `invalidated`.

[Migrate to v3](/developers/webhooks/migrate-to-v3) has the steps, which you can test before anything changes for your customers, and shows where every old field is now.
