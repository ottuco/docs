Follow these steps to go from a new Flutter project to your first test payment with the Checkout SDK, on Android and iOS. For all options, see the full [Flutter Checkout SDK](flutter.mdx) documentation.

## Prerequisites

- **Android:** the SDK can be used on devices running **Android 8 (Android SDK 26)** or higher.
- **iOS:** the SDK can be used on devices running **iOS 15** or higher.
- `merchantId`: the root domain of the Ottu account, excluding the `https://` or `http://` prefix (for example `sandbox.ottu.net`).
- Your [API public key](../../getting-started/authentication.md#public-key), used for authentication when communicating with Ottu's servers during the checkout process.
- Your [API private key](../../getting-started/authentication.md#api-key-auth), used only by your server. It must remain confidential and must never be shared with any clients.
- The [PG code](/glossary/#term-pg-code) (`pg_code`) of the payment gateway to pay with. See [Payment Methods](../payment-methods.md) to find yours.

:::warning
To prevent application crashes, it must be ensured that the correct parent theme is applied to the Android application. The theme configuration is defined in the `themes.xml` and/or `styles.xml` files located within the `res/values` directory. The `parent` attribute of the `style` tag should be set to `Theme.Material3.DayNight.NoActionBar`.

For reference, the configuration file can be reviewed at the following link: [themes.xml on GitHub](https://github.com/ottuco/ottu-flutter/blob/main/Sample/android/app/src/main/res/values/themes.xml#L3C58-L3C94)
:::

## SDK Configuration

### Android SDK Configuration

<ol className="stepper">
  <li className="stepper-item">
    <strong>Add the JitPack repository</strong>

  </li>
  <li className="stepper-item">

  </li>
  <li className="stepper-item">
    <strong>Check the `MainActivity` inheritance</strong>
    <div>Make sure `MainActivity` extends `FlutterFragmentActivity`:</div>

    ```kotlin
    class MainActivity : FlutterFragmentActivity()
    ```

  </li>
  <li className="stepper-item">
    <strong>Run the app</strong>

## Create a Payment Session

Your server calls the [Checkout API](../checkout-api.mdx) with your [private key](../../getting-started/authentication.md#api-key-auth). The response contains the `session_id`; send it to the app together with the amount, because the SDK needs both.

If the call fails, the response has no `session_id`. A `401` means the key is missing or wrong, for example the public key was sent instead of the private key. A `400` means a required field such as `amount`, `currency_code` or `pg_codes` is missing or invalid. See [Error Codes](../../reference/error-codes.md) for the error response format.

## Add OttuCheckoutWidget

Open the screen or widget where you plan to add the **Ottu SDK widget**, import the SDK and add the `OttuCheckoutWidget` to the desired location in your layout:

```dart
import 'package:ottu_flutter_checkout/ottu_flutter_checkout.dart';
```

```dart
OttuCheckoutWidget(
  arguments: CheckoutArguments(
    merchantId: "sandbox.ottu.net",
    apiKey: 'your Api key',
    sessionId: 'your session id',
    amount: 20.0,
    showPaymentDetails: true,
    paymentOptionsDisplaySettings: PaymentOptionsDisplaySettings(
      mode: PaymentOptionsDisplayMode.BOTTOM_SHEET,
      visibleItemsCount: 5,
      defaultSelectedPgCode: "",
    ),
  ),
),
```

To choose the payment methods shown, add [`formsOfPayment`](flutter.mdx#display-options). To start faster, pass the session details with [`setupPreload`](flutter.mdx#preloading).

## Callbacks

Callback functions are used to retrieve the payment status. These must be provided directly to the `OttuCheckoutWidget`. Add a section like below in a `*.dart` file of the app:

```dart
OttuCheckoutWidget(
  arguments: widget.checkoutArguments,
  successCallback: (message) => _handleSuccess(message),
  cancelCallback: (message) => _handleCancel(message),
  errorCallback: (message) => _handleError(message),
),

void _handleSuccess(String message) {
  _checkoutMessage.value = ("Success", message);
}

void _handleCancel(String message) {
  _checkoutMessage.value = ("Cancel", message);
}

void _handleError(String message) {
  _checkoutMessage.value = ("Error", message);
}
```

See [Callbacks](flutter.mdx#callbacks) for how the callbacks work on Android and iOS.

## Test a Payment

Run your Flutter app using the following command or by pressing the Run/Launch icon in your IDE:

```bash
flutter run
```

If all configurations and dependencies are correctly set, the app should build successfully and display the Ottu Checkout Widget. Pay with a test card for the gateway in your session's `pg_codes`. When the payment succeeds, `successCallback` is called.

- [Ottu Sandbox](../ottu-sandbox.mdx): a simulated gateway where the [test card](../ottu-sandbox.mdx#test-cards) decides the result.
- [Test Cards](../sandbox.mdx): test cards for each payment gateway's own sandbox.
