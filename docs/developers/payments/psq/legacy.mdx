# Payment Status Query v2

New integrations use [Payment Status Query v3](/developers/payments/psq-v3). The page below describes v2, which keeps working for existing integrations.

| Page | What it covers |
|---|---|
| [Payment Status Query v2](/developers/payments/psq) | Ask Ottu for a payment's status when a webhook did not arrive; the answer mirrors the format 1 and 2 payment webhook. |

## Coming from v2?

Payment Status Query v3 answers with the payment object and every attempt made on it, oldest first, and uses the v3 error format. `refund_queued` is named `refund_pending`, and `invalided` is `invalidated`. [Here is how to migrate](/developers/payments/psq-v3#differences-from-v2): every difference from v2, side by side.

## What's Next?

- [Payment Status Query v3](/developers/payments/psq-v3): the current API.
- [Webhooks](/developers/webhooks): get status changes pushed instead of asking for them.
